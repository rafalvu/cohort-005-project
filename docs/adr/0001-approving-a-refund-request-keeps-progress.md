# Approving a Refund Request keeps the student's progress

When a Platform Admin approves a Refund Request on an Individual Purchase, the buyer loses the Enrollment granted by that Purchase, unless a Claimed Seat still grants access (see [ADR 0004](0004-an-enrollment-is-not-tied-to-a-purchase.md)), but keeps their lesson progress, watch history, quiz attempts, comments and rating. Deleting it can't be undone, the watch history is the evidence the approval was decided on, and a student who buys again or claims a Seat later should pick up where they left off. Rows for a student with no Enrollment are expected, not orphans to clean up.
